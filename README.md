# FinanceTracker

A responsive personal finance tracking web application built as a Software Engineering final project.

## Features
- Dashboard with balance, income and expense totals
- Expense breakdown chart
- Monthly income/expense chart
- Add, edit and delete transactions
- Transaction search and filtering
- Monthly category budgets
- Browser-based data persistence using LocalStorage
- Responsive design
- No server required; deployable on GitHub Pages

## Technology
HTML5, CSS3, JavaScript, LocalStorage and Chart.js.

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local server such as VS Code Live Server.

## GitHub Pages deployment
1. Create a GitHub repository, e.g. `financetracker`.
2. Upload all files and folders while preserving the structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Your URL will normally be:
   `https://YOUR-USERNAME.github.io/financetracker/`

## Team note
This is a demo/student finance application. It stores data in the user's browser and should not be used for real financial records containing sensitive information.
